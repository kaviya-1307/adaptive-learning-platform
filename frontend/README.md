# Frontend — LeetCode Adaptive Learning Platform

React + Vite frontend for the AI-Driven Adaptive Learning and Problem Recommendation Platform.

## Setup Instructions

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start Vite Dev Server**:
   ```bash
   npm run dev
   ```

3. **Access Application**:
   Open browser at `http://localhost:5173`

The frontend automatically connects to the FastAPI backend at `http://localhost:8000/api/health` and displays the real-time service status.
